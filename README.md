# CarExpense Tracker v1.4.1 BÉTA

## Változások
- A Beállítások második menüsorában, a Határidők mellett önálló **Névjegy** gomb.
- A Névjegy mobilbarát felugró ablakban jelenik meg, a meglévő PWA-ikonnal, rövid leírással, adattárolási információval és GitHub-hivatkozással.
- A verziószámra kattintva a Névjegy bezárul, és külön, görgethető **Verziótörténet** ablak nyílik.
- A Súgóból kikerült a Névjegy és a Verziótörténet; a funkcióleírások megmaradtak.
- Service worker gyorsítótár verziószáma frissítve.
- A szinkronizációs és adatkezelési működés változatlan.

## Telepítés
A ZIP tartalmát a GitHub repository gyökerébe kell feltölteni. A meglévő telepített PWA-t **nem kell törölni**. A Beállítások > Adatkezelés > Alkalmazásfrissítés ellenőrzése funkcióval frissíthető.
